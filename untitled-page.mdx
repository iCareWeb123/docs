    ### Cara mengisi kolom Service pada kolom table template icare email :

    Cara untuk mengisi table template Permintaan service silahkan isi di kolom no 11 dengan (Y) jika ada permintaan untuk service pada mesin Tersebut dan sebutkan untuk keluhannya pada kolom table no 12 pada table template Icare Email ( bisa di liat pada contoh gambar Table di bawah Ini untuk Mengisi permintaan Service ) dan untuk pengisihan pada kolom **Permintaan Service** harus sesuai dengan kendala yanga ada pada mesin seperti notifikasi pada mesin jika terjadi eror di mesin ada notifikasi eror code yang terlampir pada layar mesin ( contoh gambar mesin yang terdapat notifikasi eror code seperti gambar di bawah ).
