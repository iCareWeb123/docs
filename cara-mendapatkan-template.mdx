**Ada dua cara untuk mendapatkan Template iCare Email:**

1. Kirim Email Kosong ke [icare@astragraphia.co.id](mailto:icare@astragraphia.co.id) :  \
   Pelanggan akan mendapatkan email balasan seperti di bawah ini. Klik tombol reply, kemudian Isi semua data dengan lengkap dan kirim kembali ke [iCare@astragraphia.co.id](mailto:iCare@astragraphia.co.id)
   ![Image (1)](/images/image-\(1\).png)
2. Download Template di:\
   \
   A. Untuk Microsoft Outlook : [http://tiny.cc/icare-email-outlook](http://tiny.cc/icare-email-outlook)

- Klik Download kemudian buka dengan Microsft Outlook

<Frame>
  ![Image (2) 1](/images/image-\(2\)-1.png)
</Frame>

- Akan terbuka jendela seperti di bawah ini. Isi dengan lengkap dan kirim kan kembali ke [iCare@astragraphia.co.id](mailto:iCare@astragraphia.co.id)

<Frame>
  ![Image (3) 1](/images/image-\(3\)-1.png)
</Frame>

B. Untuk Gmail : [http://tiny.cc/icare-email-gmail](http://tiny.cc/icare-email-gmail) (buka link hanya dengan browser Google Chrome)

- Klik tombol Preview in Gmail
